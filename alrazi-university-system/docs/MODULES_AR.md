# دليل وحدات منصة الرازي الذكية

## 1. لوحة القيادة
تعرض مؤشرات عامة مثل عدد الطلاب وأعضاء هيئة التدريس والمقررات ومعدل الحضور، إلى جانب مخطط نشاط وتوزيع افتراضي للطلاب وتقويم وأحدث العمليات. الأرقام الظاهرة للتوضيح وليست إحصاءات رسمية.

## 2. الشؤون الأكاديمية

| الوحدة | الغرض | أمثلة على البيانات |
|---|---|---|
| الطلاب | الملف الأكاديمي للطالب | الرقم الجامعي، الاسم، البرنامج، المستوى، حالة القيد ووسائل التواصل |
| أعضاء هيئة التدريس | ملفات الأكاديميين | الرقم الوظيفي، الرتبة، التخصص، القسم وبيانات الاتصال |
| الكليات والأقسام | بناء الهيكل الأكاديمي | الكلية، القسم، المسؤول، البرامج والحالة |
| البرامج والمقررات | دليل البرامج والخطط الدراسية | رمز المقرر، اسمه، الساعات، المستوى والمتطلبات السابقة |
| الجداول الدراسية | جدولة الشعب والمحاضرات | اليوم، الوقت، المقرر، المحاضر، القاعة ونوع المحاضرة |
| الاختبارات والدرجات | تنظيم التقييم الأكاديمي | الاختبارات، الأوزان، الدرجات، التغذية الراجعة والمعدل |
| الحضور والغياب | توثيق حضور الطلبة | جلسة المحاضرة، التاريخ، حاضر/غائب/متأخر/بعذر |

## 3. الخدمات الطلابية

| الوحدة | الغرض | أمثلة على البيانات |
|---|---|---|
| الرسوم والمدفوعات | إدارة الالتزامات المالية | الرسوم الدراسية والتسجيل والبطاقات والأنشطة والفواتير والسداد |
| المنح | تتبع الدعم المالي | نوع المنحة، نسبة التغطية، الطالب، الفصل وحالة الموافقة |
| المكتبة | تنظيم مصادر التعلم | الكتب، النسخ، مواقع الرفوف، الإعارة والإرجاع والغرامات |
| المختبرات | إدارة الموارد العملية | المختبر، السعة، المشرف، الحالة والحجوزات |
| الأنشطة والأندية | إدارة الحياة الطلابية | النادي، الفعالية، التسجيل، المشاركون والحضور |
| السكن الجامعي | متابعة الغرف والتسكين | المباني، الغرف، السعة، التخصيص وفترات الإقامة |
| النقل والمواصلات | تنظيم خطوط النقل | المسارات، المركبات، السائقون واشتراكات الطلاب |
| المقصف والخدمات | إدارة الخدمات داخل الحرم | منافذ الطعام، الأصناف، الطلبات والأسعار |
| مواقف السيارات | تنظيم المواقف | مناطق المواقف، التصاريح، المركبات وتواريخ الصلاحية |
| المخازن والعُهد | متابعة الأصول والمخزون | الأصناف، الكميات، المخازن وحركات الصرف والاستلام |

## 4. الإدارة والتحليل

- **الإعلانات والتنبيهات:** نشر إعلانات حسب الفئة المستهدفة وربط التنبيهات بحساب المستخدم.
- **التقارير والإحصاءات:** ملخص أعداد الطلاب، التسجيل في المقررات، الحضور والأرصدة المالية.
- **سجل التدقيق:** توثيق العمليات المهمة: من نفذها، ومتى، وعلى أي سجل.
- **إدارة المستخدمين والصلاحيات:** أدوار مقترحة مثل مدير النظام، القبول والتسجيل، عضو هيئة التدريس، المالية والطالب.

## 5. ما المقصود بالنسخة التجريبية؟

الموقع المعروض يثبت شكل الواجهة ومسارات التنقل والتعامل المحلي الأساسي مع سجلات تجريبية. عمليات الإضافة والحذف والتصدير تعمل محلياً في المتصفح. أما نظام الصلاحيات، تسجيل الدخول، مزامنة الأجهزة، الإرسال الآلي للتنبيهات، وربط MySQL فتحتاج إلى Backend وخدمة API قبل اعتبار المنصة نظاماً تشغيلياً.

## 6. سيناريو استخدام مقترح

1. يسجل مسؤول النظام الدخول عبر خادم آمن.
2. تضيف وحدة القبول الطالب وتربطه ببرنامج وفصل قبول.
3. ينشئ القسم المقررات والشعب ويحدد عضو هيئة التدريس والقاعة والوقت.
4. يسجل الطالب في الشعب المتاحة.
5. يرصد عضو هيئة التدريس الحضور والدرجات.
6. تصدر الإدارة المالية الفواتير وتوثق المدفوعات.
7. يستفيد الطالب من المكتبة والأنشطة والسكن والنقل بحسب الصلاحيات.
8. تعرض لوحة القيادة تقارير مجمعة بعد قراءة البيانات الفعلية من قاعدة البيانات.
