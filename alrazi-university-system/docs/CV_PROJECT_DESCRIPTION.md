# وصف المشروع للسيرة الذاتية (CV)

## صياغة عربية

**منصة الرازي الذكية لإدارة الجامعة — مشروع أكاديمي مستقل**  
تصميم وتطوير نموذج أولي لواجهة ويب عربية لإدارة العمليات الجامعية، يشمل لوحة قيادة وموديولات الطلاب وأعضاء هيئة التدريس والأقسام والمقررات والجداول والاختبارات والحضور والرسوم والمكتبة والمختبرات والأنشطة والسكن والنقل والمقصف ومواقف السيارات والمخازن والإعلانات والتقارير. أعددت مخطط قاعدة بيانات علائقية باستخدام MySQL مع علاقات ومفاتيح خارجية وفهارس وViews للتقارير، وصممت واجهة متجاوبة باستخدام HTML وCSS وJavaScript.

**التقنيات:** HTML5, CSS3, JavaScript, MySQL, Git, GitHub.

## English CV entry

**Al-Razi University Management Platform | Independent Academic Project**  
Designed and built an Arabic RTL university-management web prototype featuring a dashboard and modules for students, faculty, departments, courses, schedules, exams, attendance, finance, library, laboratories, activities, housing, transportation, cafeteria, parking, inventory, announcements, and reports. Designed a relational MySQL database with foreign keys, constraints, indexes, and reporting views. Built a responsive front end using HTML, CSS, and JavaScript.

**Technologies:** HTML5, CSS3, JavaScript, MySQL, Git, GitHub.
