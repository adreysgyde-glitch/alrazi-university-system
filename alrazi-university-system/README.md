# منصة الرازي الذكية لإدارة الجامعة

**Al-Razi University Management Platform — Academic Demo**  
تصميم وإعداد: **إدريس محمد صالح علي شرف الدين**  
التخصص: تقنية المعلومات (IT)  

> هذا مشروع أكاديمي مستقل لعرض فكرة نظام إدارة جامعي متكامل. ليس بوابة رسمية لجامعة الرازي، ولا يمثل الجامعة أو يتصل بأنظمتها. جميع الأسماء والأرقام والسجلات الموجودة في النسخة التجريبية بيانات افتراضية.

## فكرة المشروع

منصة ويب عربية باتجاه RTL تجمع وحدات الإدارة الأكاديمية والخدمات الطلابية والإدارة التشغيلية في واجهة موحدة، مع لوحة قيادة ومؤشرات ورسوم بيانية وجداول قابلة للبحث وإضافة السجلات وتصديرها.

## أبرز المميزات الموجودة في النسخة الحالية

- واجهة عربية متجاوبة مع الكمبيوتر والتابلت والهاتف.
- لوحة قيادة بإحصاءات ومخطط نشاط وتوزيع توضيحي للطلاب.
- إدارة تجريبية لسجلات الطلاب وأعضاء هيئة التدريس والكليات والأقسام.
- كتالوج البرامج والمقررات والجداول الدراسية.
- أقسام الاختبارات والدرجات والحضور والغياب.
- الرسوم والفواتير والمدفوعات والمنح والأقساط ضمن تصميم قاعدة البيانات.
- المكتبة والإعارة والمختبرات والحجوزات.
- الأنشطة والأندية والسكن الجامعي والنقل والمقصف ومواقف السيارات والمخازن والعُهد.
- الإعلانات والتنبيهات والتقارير والإعدادات.
- إضافة سجل وحذفه والبحث في الجداول وتصدير CSV ونسخة JSON.
- حفظ تعديلات العرض محلياً داخل المتصفح باستخدام `localStorage`.
- مخطط قاعدة بيانات MySQL مع علاقات ومفاتيح خارجية وفهارس وقيود وعروض تقارير (Views).

## تشغيل الموقع محلياً

1. فك ضغط المشروع.
2. افتح المجلد.
3. شغّل `index.html` في متصفح حديث مثل Chrome أو Edge.
4. جرّب التنقل من القائمة الجانبية، ثم افتح قسم الطلاب وأضف سجلاً تجريبياً.

لأفضل تجربة، شغّل مجلد المشروع عبر خادم محلي بسيط في محرر الأكواد، لكن النسخة الأمامية لا تحتاج إلى تثبيت حزم أو خادم لكي تُعرض.

## إعداد قاعدة البيانات MySQL

1. افتح phpMyAdmin أو MySQL Workbench.
2. اختر **Import** في phpMyAdmin.
3. حدّد الملف `database/alrazi_university.sql` ثم نفّذ الاستيراد.
4. سيُنشأ مخطط باسم `alrazi_university` مع الجداول والعلاقات والعينات التجريبية.
5. راجع `docs/DATABASE_GUIDE_AR.md` لمعرفة وظيفة الجداول وطريقة ربطها بتطبيقك.

قاعدة البيانات مخصصة لـ **MySQL 8.0 أو أحدث**، والترميز `utf8mb4` لدعم العربية. يمكن تكييفها إلى MariaDB أو PostgreSQL، لكن قد تحتاج بعض أنواع البيانات والقيود إلى تعديل.

## مهم: ما الذي يعمل الآن وما الذي يحتاج إلى ربط؟

الواجهة الحالية نموذج Front-end يعمل مباشرة في المتصفح. عند إضافة/حذف السجلات من الموقع، تُحفظ هذه التعديلات في `localStorage` على نفس الجهاز والمتصفح فقط. ملف SQL هو قاعدة البيانات العلائقية الجاهزة للربط بتطبيقك، لكن الواجهة لم تُربط بعد بخادم API؛ لذلك لا تُرسل عمليات الموقع تلقائياً إلى MySQL.

لتحويله إلى نظام إنتاجي فعلي، أنشئ Backend/API (مثل PHP أو Node.js أو Java أو C#) يتصل بقاعدة البيانات، ثم استبدل عمليات `localStorage` بطلبات API. يجب إضافة تسجيل دخول آمن وصلاحيات بحسب الدور، والتحقق من المدخلات، وسجل تدقيق، ونسخ احتياطي، وحماية البيانات الشخصية والمالية قبل استخدام أي بيانات حقيقية.

## النشر على GitHub Pages

1. أنشئ مستودعاً عاماً جديداً باسم مثل `alrazi-university-system`.
2. ارفع جميع محتويات المجلد، وليس ملف `index.html` وحده.
3. من **Settings → Pages** اختر النشر من الفرع `main` والمجلد `/root` (أو `/` حسب واجهة GitHub).
4. احفظ الإعداد وانتظر اكتمال نشر GitHub Pages.
5. رابط الموقع سيظهر في صفحة GitHub Pages للمستودع.

GitHub Pages يستضيف ملفات الواجهة الثابتة فقط، ولا يشغّل MySQL أو Backend. احتفظ بقاعدة البيانات في خادم آمن ولا ترفع كلمات مرور أو بيانات حقيقية إلى GitHub.

## بيانات الاعتماد والأمان

لا توجد في هذه النسخة شاشة دخول حقيقية أو حسابات تشغيل. يوجد جدول `users` في مخطط SQL لمرحلة الربط المستقبلية، لكن يجب تخزين كلمات المرور باستخدام bcrypt أو Argon2 من جانب الخادم. بيانات الحسابات التجريبية في ملف SQL لا تحتوي على كلمة مرور صالحة.
